# 01 · 环境与工具

## 1. 必需工具

| 工具 | 版本 | 用途 |
|---|---|---|
| apktool | 2.9+ | 解包/回编译资源与 manifest |
| jadx | 1.4+ | Java 反编译（读业务逻辑） |
| baksmali/smali | — | dex ↔ smali（读被混淆的类） |
| Android build-tools | **35.0.0** | `d8` 把 class 转 dex |
| Android platform | **android-34** | javac 的 `android.jar` |
| zipalign / apksigner | build-tools | 对齐与签名 |
| Python 3 | 3.10+ | 全部脚本 |
| objdump (aarch64) | binutils-aarch64 | 反汇编 `libmd5.so` 等 native 库 |
| capstone (py) | 5.x | 脚本化反汇编 |

### 安装（中国镜像源）

```bash
# Python 包
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
pip install capstone zstandard

# Android SDK（命令行工具 + 指定版本）
#   platforms;android-34
#   build-tools;35.0.0

# 反汇编
sudo apt install binutils-aarch64-linux-gnu
```

## 2. 关键坑位（务必遵守）

### 2.1 d8 必须用 build-tools 35.0.0

build-tools 33/34 的 `d8` 处理**匿名内部类**时会内部 NPE：
```
java.lang.NullPointerException
    at com.android.tools.r8.dex.FileWriter...
```
本项目 shim 与插件大量使用匿名类，因此固定：

```bash
D8=/tmp/android-sdk/build-tools/35.0.0/d8
AJ=/tmp/android-sdk/platforms/android-34/android.jar
```

### 2.2 必须保留 `META-INF/services`

回包时若丢失 `META-INF/services/`，Ktor/Kotlin 协程会报：
```
Module with the Main dispatcher is missing
```
`scripts/repack.py` 已显式保留该目录。

### 2.3 native 库的取舍

| 库 | 处理 |
|---|---|
| `libDexHelper*.so` | **删除**（壳的运行时） |
| `libdexjni.so` | **保留**（`com.fort.andjni.JniLib` 依赖，删了会 `UnsatisfiedLinkError`） |
| `libmd5.so` | 保留（签名算法） |

## 3. 目录约定

```
/tmp/android-sdk/                 # Android SDK
  platforms/android-34/android.jar
  build-tools/35.0.0/d8

<Ets>/                            # 工作目录
  E听说中学_7.0.67.2495.apk        # 原始 APK
  apktool_out/                    # apktool 解包结果（含 lib/AndroidManifest.xml）
  jadx_out/                       # jadx 反编译
  unpacked_dex/                   # 去壳后的真实 dex（dex_out_0..10.dex）
  unpacked_dex_smali/             # baksmali 出来的 smali（读混淆代码用）
  project/                        # 本仓库（构建工程）
```
