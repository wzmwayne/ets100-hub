# 10 · 复现步骤

从原始 APK 到成品 APK + 插件 + PK 客户端，全流程。

## 0. 前置

```bash
# Android SDK
/tmp/android-sdk/platforms/android-34/android.jar
/tmp/android-sdk/build-tools/35.0.0/d8        # 必须 35.0.0

# 工具
apktool, jadx, baksmali, zipalign, apksigner, python3(capstone)
```

工作目录约定见 `docs/01-环境与工具.md`。

---

## 1. 解包与反编译（一次性，产物落盘复用）

```bash
cd /path/to/work

apktool d -f E听说中学_7.0.67.2495.apk -o apktool_out
jadx -d jadx_out E听说中学_7.0.67.2495.apk
```

## 2. 去壳，提取真实 dex

```bash
# 从壳 so 中提取 11 个真实 dex
python3 scripts/dex_extract_all.py apktool_out/lib/arm64-v8a/libDexHelper1788501371.so \
        unpacked_dex 0xF50

# 尾部 insns 原地写回（修 map 段重复）
python3 scripts/dex_restore_inline.py unpacked_dex unpacked_dex_fixed

# 修 codemap
python3 scripts/dex_fix_codemap.py unpacked_dex_fixed

# 反编译成 smali 便于搜索
for f in unpacked_dex/dex_out_*.dex; do
  baksmali d "$f" -o unpacked_dex_smali/$(basename $f .dex)
done
```

详见 `docs/02-去壳与DEX提取.md`。

## 3. 构建成品 APK

```bash
cd project/                 # 本仓库根目录
bash scripts/build_safe.sh  # → deshell/safe28-release.apk
```

流水线细节见 `docs/03-改包与构建.md`。

## 4. 安装

```bash
adb install -r deshell/safe28-release.apk
# 或拷贝到 /sdcard/Download/ 用文件管理器安装
```

安装后：

- 桌面出现 **E听说中学**（包名 `com.ets100.repackapp`，可与原版共存）
- 任意界面右下角出现 **HUB** 浮球
- 首次启动若原版有登录态不会共享（不同包名），需要重新登录

## 5. 编译并安装插件

```bash
bash scripts/build_plugin.sh          # → plugins/etshub-plugin-*.dex

# 上传（需 App 已运行 + 局域网/端口转发可达 8765）
curl -X POST "http://127.0.0.1:8765/plugins/upload?name=etshub-plugin-SuperAutoPkPlugin.dex" \
     --data-binary @plugins/etshub-plugin-SuperAutoPkPlugin.dex

curl "http://127.0.0.1:8765/restart"  # 必须重启才生效
```

或在 HUB 面板 → 打开管理网页 → 上传安装 → 按提示重启。

## 6. 使用 PK 自动化

### 6.1 App 内（图形化）

1. 进入 **单词PK** 页面
2. 左下角出现按钮：
   - 未选教材/单元 → 灰色「请选择PK范围」
   - 已选 → 橙色「超级自动答题」
3. 点按钮 → 填参数（题数/用时/满分/局数/并发）→ 开始
4. 看进度框与结果汇总

### 6.2 Python 客户端（批量/压测）

```bash
python3 scripts/pk_client.py probe            # 先自检
python3 scripts/pk_client.py pk 10 0          # 单局
python3 scripts/pk_client.py repk 10 2000 0 100   # 2000 局 / 100 线程
```

## 7. 常见故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 回编译报 `Duplicate map section of type 2001` | `dex_restore_inline.py` 必须是"原地写回"版本 |
| 启动即闪退，日志 `Module with the Main dispatcher is missing` | 打包时丢了 `META-INF/services` |
| `UnsatisfiedLinkError: JniLib.cV` | 误删了 `libdexjni.so`（只应删 `libDexHelper*`） |
| d8 报 NPE | 用了 build-tools 34/33，换成 **35.0.0** |
| 请求返回 `10003` | 签名错（检查密钥 `717e…` 与拼接顺序 `pid+time+body+key`） |
| 请求返回 400 (istio-envoy) | 路径写错，必须 `POST https://api.ets100.com/<r>` |
| `9002 DATA_SERIALIZATION_INVALID` | `word_ids`/`question_ids` 必须是 `_` 拼接字符串 |
| `9001 API_SERVICE_INNER_INVALID` | 词数过多（>20），PK 取 10 个 |
| 插件不生效 | 忘重启（安装后不再动态重载） |
| 覆盖安装失败 | 签名不一致，需用同一 `keys/deshell.keystore` |

## 8. 从零开始的完整命令清单

```bash
# --- 一次 ---
apktool d -f app.apk -o apktool_out
jadx -d jadx_out app.apk
python3 scripts/dex_extract_all.py apktool_out/lib/arm64-v8a/libDexHelper*.so unpacked_dex 0xF50

# --- 每次构建 ---
cp -r unpacked_dex ../unpacked_dex    # 若不在预期路径
bash scripts/build_safe.sh

# --- 插件 ---
bash scripts/build_plugin.sh
curl -X POST "http://127.0.0.1:8765/plugins/upload?name=x.dex" --data-binary @deshell/etshub-plugin-X.dex
curl "http://127.0.0.1:8765/restart"

# --- PK ---
python3 scripts/pk_client.py repk 10 100 0 8
```
