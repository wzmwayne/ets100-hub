# 09 · 脚本说明

全部脚本位于 `scripts/`，Python 3 编写，无第三方依赖（除 `zstandard` 可选）。

## 1. 去壳 / dex 修复

| 脚本 | 作用 |
|---|---|
| `dex_extract_all.py` | 从 `libDexHelper*.so` 的加密 blob 中提取全部真实 dex（本例 11 个，基址 `0xF50`） |
| `dex_restore_inline.py` | 把 `BBbb.dgc` 尾部 insns **原地写回**（修 `Duplicate map section of type 2001`） |
| `dex_fix_codemap.py` | 修 `code_item` / `debug_info` 偏移表 |
| `dex_unfinal.py` | 清除指定 dex 中类的 `ACC_FINAL`（`EtsApp` 需要被继承） |
| `fix_bad_resource_names.py` | 修复资源名非法字符（回编译失败时用） |
| `replace_dex.py` | 用新 dex 目录直接替换 APK 内的 dex |

## 2. 清单 / 资源处理

| 脚本 | 作用 |
|---|---|
| `axml_strip_push.py` | 二进制 AXML 级移除全部推送组件与权限（友盟/极光/小米/华为/OPPO/vivo/魅族…） |
| `axml_repackage.py` | 改包名 + 替换 `<application android:name>` |
| `axml_patch.py` | AXML 通用二进制补丁工具（底层） |
| `patch_manifest.py` | 早期文本级 manifest 补丁 |

## 3. 构建

| 脚本 | 作用 |
|---|---|
| `build_shim.sh` | 编译 HUB shim（javac + d8 → `shim_java/shim.dex`） |
| `build_plugin.sh` | 每个插件编译为一个 dex（`d8 --classpath shim_java/classes`） |
| `build_deshell.sh` | 仅去壳重建（原包名） |
| `build_repack.sh` | 去壳 + 改包名 |
| `build_nopush.sh` | 去壳 + 改包名 + 去推送 |
| **`build_safe.sh`** | **主线**：去壳 + 改包名 + 去推送 + 防闪退 + HUB（当前输出 `safe28`） |
| `repack.py` | 重组 APK（新 manifest + 真实 dex + shim.dex，保留 `META-INF/services`） |
| `patch_anim.py` | 构建期 smali 级插桩：PK 反馈动画时长 / 切题延时 → `Tuning` |
| `dex_rename_pkg.py` | 修改 dex 内的包名常量 |

## 4. PK 相关

| 脚本 | 作用 |
|---|---|
| **`pk_client.py`** | **独立 Python PK 客户端**（详见下） |
| `pk_sim.py` | 早期方案：从 App HTTP 导出题目，再用 App 仓库提交 |
| `pk_client_probe.py` | 协议探测（历史遗留） |

### `pk_client.py` 命令

```bash
python3 pk_client.py pk   [题数=10] [用时秒=0]
python3 pk_client.py repk [题数=10] [局数=5] [用时秒=0] [线程数=1]   # 线程数=0 => 动态并发
python3 pk_client.py tune [每档秒数=4]        # 探测最优并发
python3 pk_client.py probe                    # 连通性 + 签名自检
python3 pk_client.py units                    # 单元列表
python3 pk_client.py struct 1,2,3             # 查题目(调试)

# 省略 repk 也可：
python3 pk_client.py 10 50 0 8
# 详细网络流程（token 已脱敏）：
python3 -u pk_client.py 10 50 0 8 -v > pk.log 2>&1 &
```

输出示例：

```
进度 69/300 (23.0%) | 1.58 局/s | 并发 4 | 已用 0:44 | 剩余 2:25
====================================================
共 300 局 | 并发 动态(结束 16) | 胜 300 平 0 负 0 失败 0 | 成长豆 +300
总耗时 17.1 秒 | 吞吐 1053.0 局/分 (17.55 局/秒)
单局延迟 平均 0.52 秒 | 最快 0.26 | 中位 0.51 | 最慢 5.54
我方用时 0 秒/局 | 对手用时 平均 19.0 秒 (最快 19 / 最慢 19)
```

依赖：

| 依赖 | 说明 |
|---|---|
| `GET http://127.0.0.1:8765/account` | 取 token / baseUrl / 版本 / p7（**唯一**对 App 的依赖） |
| 签名 | **本地实现**：`md5("androidV3"+time+body+"717e…")` |

> 也可用 `probe` 与 App 的 `/sign` 做自检，不一致会自动回退到调用 App 签名。
