# 07 · 插件开发指南

## 1. 最小插件

```java
package com.ets.unpack.plugin;

import com.ets.unpack.hub.Hub;
import com.ets.unpack.hub.IPlugin;
import java.util.Map;

public class MyPlugin implements IPlugin {
    public String name()        { return "我的插件"; }
    public String version()     { return "1.0.0"; }
    public String description() { return "/hello 打个招呼"; }

    public void install(final Hub hub) {
        // 菜单项
        hub.add(new Hub.Feature() {
            public String title() { return "我的功能"; }
            public void run(android.app.Activity a, Hub h) { h.toast("hello"); }
        });
        // HTTP 路由
        hub.addRoute("/hello", new Hub.Route() {
            public String handle(Map<String, String> q) { return "{\"ok\":true}"; }
        });
        hub.dbg("MyPlugin installed");
    }
}
```

## 2. 编译

```bash
bash scripts/build_plugin.sh
# 输出: plugins/etshub-plugin-<类名>.dex   （只含该插件及其内部类）
```

脚本核心（`scripts/build_plugin.sh`）：

```bash
AJ=/tmp/android-sdk/platforms/android-34/android.jar
D8=/tmp/android-sdk/build-tools/35.0.0/d8          # 必须 35.0.0
CLS=$ROOT/shim_java/classes                        # Hub 的 class，用于编译依赖

javac -encoding UTF-8 --release 8 -nowarn -cp "$CLS:$AJ" -d /tmp/plug_cls $(find $SRC -name '*.java')

for src in $(find $SRC -name '*.java'); do
  name=$(basename $src .java)
  files=$(find /tmp/plug_cls -name "$name.class" -o -name "$name\$*.class" | sort)
  "$D8" --min-api 21 --lib "$AJ" --classpath "$CLS" --output /tmp/plug_out $files
  cp /tmp/plug_out/classes.dex "$ROOT/deshell/etshub-plugin-$name.dex"
done
```

## 3. 安装到设备

三种方式：

| 方式 | 操作 |
|---|---|
| 网页 | HUB 面板 → 打开管理网页 → 选择 dex → 上传安装 |
| HTTP | `curl -X POST 'http://127.0.0.1:8765/plugins/upload?name=x.dex' --data-binary @x.dex` |
| 文件 | 把 dex 放 `/sdcard/Download/` 后 `/plugins/install?src=/sdcard/Download/x.dex` |

> **安装/删除后必须重启应用**（`GET /restart`），插件只在启动时加载。

## 4. Hub 可用能力

| API | 说明 |
|---|---|
| `hub.add(Feature)` | 注册面板菜单项 |
| `hub.addRoute(path, Route)` | 注册 HTTP 路由（`Map<String,String>` 查询参数） |
| `hub.current()` | 当前 Activity |
| `hub.ctx()` | Application Context |
| `hub.ui()` | 主线程 Handler |
| `hub.contentView(activity)` | Activity 的 `android.R.id.content` (FrameLayout) |
| `hub.toast(s)` / `hub.showText(a,title,text)` | 提示 / 文本弹窗 |
| `hub.dp(float)` | dp→px |
| `hub.dbg(s)` | 写调试日志（`GET /dbg`） |
| `hub.findViewModel(a, className)` | 反射查找 ViewModel |
| `Hub.call(o, method[, types, args])` | 反射调用 |
| `Hub.field(o, name)` | 反射读字段 |
| `Hub.json(s)` | JSON 字符串转义 |
| `hub.restart()` | 重启应用 |

## 5. 访问 App 内部（反射要点）

### 5.1 包名没有变

虽然 APK 包名改成了 `com.ets100.repackapp`，
但 **dex 内的 Java 包名仍保留**（只有 manifest/applicationId 与部分引用被替换），
所以可以直接：

```java
Class.forName("com.ets100.network.EtsHttp");
Class.forName("com.ets100.secondary.utils.p7");
Class.forName("com.ets100.syncword.viewmodel.WordBattleViewModel");
```

### 5.2 读取账号/配置

```java
Class<?> eh = Class.forName("com.ets100.network.EtsHttp");
Object etsHttp = eh.getField("a").get(null);          // 单例
String token  = String.valueOf(Hub.call(Hub.call(etsHttp, "h"), "a"));
Object options = Hub.call(Hub.call(etsHttp, "f"), "a");
String etsApp = String.valueOf(Hub.call(options, "i"));
String base   = String.valueOf(Hub.call(Hub.call(options, "j"), "e"));
String ver    = String.valueOf(Hub.call(Class.forName("od.a").getField("a").get(null), "d"));
```

### 5.3 读取 MMKV(p7)

```java
Class<?> c = Class.forName("com.ets100.secondary.utils.p7");
Map<?,?> m = (Map<?,?>) c.getMethod("f").invoke(null);
Object v = m.get("sp_pk_unit_id_267695413");
```

> **坑**：值是 `String`/`Integer` 混存，`Map<String,String>` 强转会
> `ClassCastException`，统一用 `String.valueOf()`。

## 6. UI 经验

### 6.1 悬浮按钮不要直接用 OnClickListener + 拖动

要么纯点击（`setOnClickListener`），要么用统一 `OnTouchListener`
（位移 > 6dp 才算拖动，否则视为点击），否则拖动会误触。

### 6.2 只在特定页面显示

Hub 没有暴露 Activity 回调给插件，插件可自行轮询：

```java
while (true) {
    Activity a = hub.current();
    if (a != null && a.getClass().getName().startsWith("com.ets100.syncword.ui.pk")) refresh(a);
    Thread.sleep(500);
}
```

再把自绘 `TextView` 加到 `hub.contentView(a)`：

```java
FrameLayout root = hub.contentView(a);
FrameLayout.LayoutParams lp = new FrameLayout.LayoutParams(dp(120), dp(42));
lp.gravity = Gravity.BOTTOM | Gravity.START;
lp.setMargins(dp(10), 0, 0, dp(150));      // HUB 浮球在右下角，避免重叠
root.addView(btn, lp);
```

### 6.3 并发竞态

配置懒加载（token/ver/base）**必须同步**，否则并发时可能读到半初始化状态：

```java
private synchronized void cfg() throws Exception {
    if (base != null && token != null && ver != null && etsApp != null) return;
    String t = ..., e = ..., b = ..., v = ...;   // 先全部算出来
    token = t; etsApp = e; base = b; ver = v;    // 再一次性发布
}
```

## 7. 调试技巧

| 手段 | 用法 |
|---|---|
| 调试日志 | `hub.dbg("...");` → `GET /dbg` |
| 反射调用任意方法 | `GET /call?target=vm&method=NAME&arg0=1` |
| View 树 | `GET /view/dump?depth=6` |
| ViewModel dump | `GET /vm/dump` |
| 抓真实网络报文 | 见 `OraclePlugin`（把日志拦截器挂到 Retrofit 的 `callFactory` 上） |

### 用 App 当“签名 oracle”

调试协议时，把 App 自己的 native 签名暴露成 HTTP 路由（`OraclePlugin`）：

```java
Class<?> c = Class.forName("com.ets100.secondary.utils.JniUtils");
Object inst = c.getField("a").get(null);
Method m = c.getMethod("getSign", String.class);
return String.valueOf(m.invoke(inst, s));     // /sign?s=<time+body>
```

这比反复猜算法快得多（本项目就是靠它发现密钥抄错一位）。
