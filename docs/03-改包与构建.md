# 03 · 改包与构建

## 1. 目标

把去壳后的 APK 变成**可安装、可覆盖升级、无推送、不闪退、带 HUB 框架**的成品：

| 改动 | 目的 |
|---|---|
| 包名 `com.ets100.secondary` → `com.ets100.repackapp` | 与原版共存，避免签名冲突 |
| Application 指向 `com.ets.unpack.repack.SafeApp` | 注入点 + 防闪退 |
| 移除全部推送组件与权限 | 去广告/去后台 |
| 打包 `shim.dex` | HUB 框架本体 |
| 动画插桩 | 单词PK 反馈/切题加速 |
| 保留 `META-INF/services` | 协程/Ktor 正常 |

## 2. 一键构建：`scripts/build_safe.sh`

```bash
ROOT=$(cd "$(dirname "$0")/.." && pwd)
WORK="$ROOT/build_work_safe"
ORIG="$ROOT/original/E听说中学_7.0.67.2495.apk"
OLD="com.ets100.secondary"
NEW="com.ets100.repackapp"
DEXSRC="$ROOT/../unpacked_dex"
UNFIDX=10                       # dex_out_10 定义 com.ets100.secondary.app.EtsApp

bash scripts/build_shim.sh                       # 1. 编译 HUB shim
unzip -p "$ORIG" AndroidManifest.xml > $WORK/AndroidManifest.xml
python3 scripts/axml_strip_push.py  $WORK/AndroidManifest.xml     # 2. 去推送
python3 scripts/axml_repackage.py   $WORK/AndroidManifest.xml $OLD $NEW com.ets.unpack.repack.SafeApp   # 3. 改包名/换 Application
python3 scripts/dex_restore_inline.py "$DEXSRC" "$WORK/dex"       # 4. 还原真实 dex
python3 scripts/patch_anim.py  "$WORK/dex/dex_out_4.dex"          # 5. 动画插桩
python3 scripts/dex_rename_pkg.py "$WORK/dex" "$OLD" "$NEW"       # 6. 改 dex 内包名
python3 scripts/dex_unfinal.py "$WORK/dex/dex_out_10.dex"         # 7. 清 final
python3 scripts/repack.py "$ORIG" "$WORK/AndroidManifest.xml" "$WORK/dex" \
        "$ROOT/shim_java/shim.dex" "$WORK/safe_dex.apk"           # 8. 重组 APK
zipalign -f -p 4 "$WORK/safe_dex.apk" "$WORK/safe_aligned.apk"    # 9. 对齐
apksigner sign --ks keys/deshell.keystore --ks-pass pass:android \
        --key-pass pass:android --out deshell/safe28-release.apk "$WORK/safe_aligned.apk"   # 10. 签名
```

## 3. 各步骤细节

### 3.1 `build_shim.sh` — 编译 HUB

```bash
javac -encoding UTF-8 --release 8 -nowarn -cp "$AJ" -d shim_java/classes $(find shim_java/src -name '*.java')
d8 --min-api 21 --lib "$AJ" --output shim_java/d8out $(find shim_java/classes -name '*.class')
cp shim_java/d8out/classes.dex shim_java/shim.dex
```

### 3.2 `axml_strip_push.py` — 去推送

直接对二进制 AXML 做字符串/节点级删除，移除以下 SDK 的组件与权限：
```
com.umeng / com.tencent.android.tpush / com.xiaomi.mipush / com.huawei.hms.push /
com.vivo.push / com.heytap.msp / com.meizu.cloud.pushsdk / com.alibaba.sdk.android.push ...
```

### 3.3 `axml_repackage.py` — 改包名 & 换 Application

- 把 manifest 中所有 `com.ets100.secondary` 前缀替换为 `com.ets100.repackapp`
- `<application android:name>` 改写指向 `com.ets.unpack.repack.SafeApp`
- 保留原始 launcher activity / 权限 / provider authority 的一致性

### 3.4 `patch_anim.py` — 构建期插桩

把单词PK 的动画时长与延时改为可调（`Tuning`）：

| 目标 | 插桩 |
|---|---|
| `com/ets100/syncword/ui/fragment/WordBattleFragment;->n0(...)` | 反馈动画时长 → `Tuning.dur(int,int)` |
| `com/ets100/secondary/utils/g;->a/b/c/f(...)` | 切题延时 → `Tuning.delay(int)` |
| `Tuning.dur` 系列内部 | 读取配置（默认 ×1.0），支持 HUB 面板/HTTP 动态改 |

### 3.5 `repack.py` — 重组 APK

- 用**新 AndroidManifest.xml** 替换原包的
- 用 `unpacked_dex` 的真实 dex 替换原包里的壳 dex
- 追加 `shim.dex`（HUB 框架 + CrashGuard + AP/CP）
- **保留** `resources.arsc`、`res/`、`assets/`（除壳数据）、`lib/`（除 `libDexHelper*`）
- **保留** `META-INF/services/`

### 3.6 签名

```
keystore : keys/deshell.keystore
storePass: android
keyPass  : android
alias    : deshell
```

自签名证书，用于本地安装与**覆盖升级**（同一签名才能覆盖安装）。

## 4. 覆盖安装注意

- 必须使用**同一个 keystore** 重新签名，否则无法覆盖安装（需先卸载，会丢数据）
- 包名不变（`com.ets100.repackapp`）才能保留 `files/`（含插件目录）

## 5. 构建产物命名约定

| 名称 | 含义 |
|---|---|
| `deshell-release.apk` | 仅去壳（原包名） |
| `repack-release.apk` | 去壳 + 改包名（含推送，已废弃） |
| `nopush-release.apk` | 去壳 + 改包名 + 去推送 |
| `safe**N**-release.apk` | + 防闪退 + HUB（当前主线，最新 `safe28`） |
