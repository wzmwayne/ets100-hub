## 2. 接口清单（Retrofit `@POST` 相对路径 = `r`）

| `r` | 关键参数 | 说明 |
|---|---|---|
| `g/pk/count` | 无 | PK 总次数/昨日次数 |
| `g/set/unit-list` | `resource_id, book_id, is_need_score, filter_noword` | 单元列表 |

| `g/pk/activity-config` / `activity-zone` / `activity-rank` | — | 活动 |

### 2.1 `word_ids` / `question_ids` 是字符串

源码（`WordBattleViewModel.B0()`）：

```java
sb.append(wordBean.getId());  sb.append("_");      // word_ids
sb2.append(questionBean.getId()); sb2.append("_");  // question_ids
...
if (sb.length() > 1) sb.deleteCharAt(sb.length() - 1);   // 去掉尾部 "_"
```

- 必须是 `"718188_718189_..."` 形式
- 传数组 → `9002 DATA_SERIALIZATION_INVALID`
- 题目只取 `question_type == 19`（英译中）；`isAlsoEnToCn` 时再加 20（中译英）

### 2.2 开局

```json
{"unit_id":28052,"book_id":969,
 "word_ids":"718188_..._718197",
 "question_ids":"1911784_..._1911838",
 "name":"","source":0,"version":1}
```

返回：

```json
{"serial_id":"24809073979909_969_28052_32445268",
 "opponent":{"name":"李**","id":30945945,
   "score":{"use_time":33,"point":9000,
     "detail":[{"answer":"C","word_id":718191,"question_id":1911802,"point":10000}, ...]}}}
```

- 题目/单词是**乱序**返回的
- **一次最多约 20 个词**，73 个词会 `9001`
- App 固定 **10 题**

### 2.3 提交

```json
{"serial_id":"...","use_time":0,"source":0,
 "score_detail":[{"point":10000,"answer":"C","word_id":718191,"question_id":1911802}, ...]}
```

返回：

```json
{"result":1,"add_bean":1,"overtime":0,"sn":"","point":10000}
```

| 字段 | 含义 |
|---|---|
| `result` | **1=胜 0=平 -1=负**（源码 `WordBattleFragment.k0()`） |
| `add_bean` | 成长豆（胜 +1，平/负 +0） |
| `point` | 我方得分（0~10000，每题满分 10000，总分取平均） |
| `overtime` | 是否超时 |

**`use_time=0` 基本必赢**：对手 `use_time` 常见 1/19/33 秒，填 1 秒时会判平。

## 3. PK 范围状态（p7 MMKV 存储）

App 用 `com.ets100.secondary.utils.p7`（MMKV 封装）保存当前选择：

| Key 模板 | 含义 | 未选默认 |
|---|---|---|
| `sp_pk_book_id_<uid>` | 教材 ID | 0 |
| `sp_pk_book_name_<uid>` | 教材名 | "" |
| `sp_pk_book_res_id_<uid>` | 教材资源 ID | 0 |
| `sp_pk_unit_id_<uid>` | 单元 ID | 0 |
| `sp_pk_unit_name_<uid>` | 单元名 | "" |
| `sp_pk_unit_code_<uid>` | BC 单元码 | "" |
| `sp_pk_word_source_<uid>` | 词源 | 0 |
| `sp_pk_index<book>_<unit>_<uid>` | 该单元已练序号 | — |
| `sp_is_first_click_pk` | 是否首次点 PK | true |

`<uid>` = `ShareViewModel.v()`（家长账号 ID，例如 `267695413`）

读取方式：
```java
Class<?> c = Class.forName("com.ets100.secondary.utils.p7");
Map<?,?> m = (Map<?,?>) c.getMethod("f").invoke(null);   // 全量快照
```
（注意：值是 `String`/`Integer` 混合，**不要强转泛型**，用 `String.valueOf()`）

ViewModel 侧对应 getter（`WordBattleInfoViewModel`）：

| getter | 来源 |
|---|---|
| `q()` | `sp_pk_book_id_<uid>`，默认 0 |
| `r()` | `sp_pk_book_name_<uid>` |
| `s()` | `sp_pk_book_res_id_<uid>` |
| `O()` | `sp_pk_unit_id_<uid>`，默认 0 |
| `Q()` | `sp_pk_unit_name_<uid>` |
| `u()` / `t()` | **会话内**字段 `int q = -1` / `String r = ""` |

判「是否已选 PK 范围」= `O()>0 && q()>0 && s()>0 && Q()!=""`
（`BaseBattleInfoActivity` / `WordBattleInfoActivity` 也是用 O()/Q() 显示当前单元）

## 4. 完整一局的调用序列

```
① g/set/word-list   {unit_id, resource_id, parent_account_id}   → 取该单元全部 word id
② g/word/struct     {word_ids:[...]}                            → 取题目 + 正确答案
   选中前 10 个有 question_type==19 的题
③ g/pk/start-word-pk{unit_id, book_id, word_ids:"a_b_c", question_ids:"x_y_z", name:"", source:0, version:1}
   → serial_id + 对手分数
④ g/pk/submit-word  {serial_id, use_time:0, source:0,
                     score_detail:[{point:10000, answer, word_id, question_id} × 10]}
   → result / add_bean / point
```

① ② 可按单元缓存，因此每局实际只有 **2 个请求**。
