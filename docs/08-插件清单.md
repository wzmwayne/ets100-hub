# 08 · 插件清单

所有插件源码在 `shim_java/plugin_sample/src/com/ets/unpack/plugin/`，
编译产物在 `plugins/`，**每个插件一个独立 dex**。

安装 = 把 dex 放进 `files/plugins/`（网页上传 / HTTP / 文件拷贝），然后**重启应用**。

---

## 1. SuperAutoPkPlugin 1.2.0 — 超级自动答题 ⭐

| 项 | 内容 |
|---|---|
| 文件 | `etshub-plugin-SuperAutoPkPlugin.dex` |
| 路由 | `GET /superpk?n=&use_time=&point=&rounds=&conc=` |
| 菜单 | 「超级自动答题(菜单)」 |
| UI | PK 页面左下角**悬浮按钮** |

功能：

- 进入 PK 模块页面（`com.ets100.syncword.ui.pk.*`）自动挂按钮
- **未选教材/单元** → 灰色按钮 **「请选择PK范围」**，点击提示先选范围
- **已选** → 橙色按钮 **「超级自动答题」**，点击弹参数框：

```
题数     [10]      用时(秒) [0]
每题满分 [10000]   局数     [1]      并发 [1]
```

- 参数写入 `SharedPreferences("superpk")` 记忆
- 执行时弹进度框：`进行中 12/100 | 胜 11 平 1 负 0 | 成长豆 +11`
- 完成汇总：胜负平、成长豆、参数、总耗时、局/秒
- 内部**完全独立直连 API**（本地 MD5 签名 + HttpURLConnection），不调用 App 业务逻辑
- 状态判定与 App 一致：`sp_pk_book_id_* / sp_pk_book_res_id_* / sp_pk_unit_id_* / sp_pk_unit_name_*`

## 2. OraclePlugin 1.2.0 — 签名/抓包探针

| 项 | 内容 |
|---|---|
| 路由 | `/sign?s=` `/rsign?d=&sn=` `/opts` `/okhttp` `/capture` `/capture/log` |

用途（逆向调试）：

| 路由 | 作用 |
|---|---|
| `/sign?s=<urlencode(time+body)>` | 调 App 原生 `JniUtils.getSign` 返回签名（**签名 oracle**） |
| `/rsign?d=<base64响应>&sn=` | 调 `getResponseSign` |
| `/opts` | 导出 Options（etsApp / etsApi / baseUrl / 灰度开关） |
| `/okhttp` | 导出 Retrofit baseUrl 与 OkHttp 拦截器列表 |
| `/capture` | **运行时抓包**：反射把日志拦截器挂到 Retrofit 的 `callFactory`，再反射触发一次真实请求，返回最终 URL / 请求体 / 响应 |

> 发现"密钥抄错一位"就是靠 `/sign` 与本地 MD5 比对。

## 3. PkApiPlugin 1.2.0 — PK 数据接口

| 项 | 内容 |
|---|---|
| 路由 | `/account` `/pk/export` `/pk/submit` |
| 菜单 | 「查看 PK 导出JSON」 |

| 路由 | 作用 |
|---|---|
| `GET /account` | 导出 p7 全量 + token / options / client_version（Python 客户端取账号用） |
| `GET /pk/export` | 从 ViewModel 导出当前 PK 的 serial / 题目 / 正确答案 / 用时 |
| `GET /pk/submit?use_time_ms=&answers=i,answer,point;...` | 用 App 自身仓库提交答案 |

## 4. InjectSolvePlugin 1.5.4 — 注入答题

| 项 | 内容 |
|---|---|
| 路由 | `/inject` `/inject/run` |
| 菜单 | 「注入答题配置」「立即注入答题」「查看注入配置」 |

## 设备上的实际加载顺序

插件目录 `/storage/emulated/0/Android/data/com.ets100.repackapp/files/plugins/`
中的 `*.dex` 会在 Application 启动时**按目录顺序**依次加载（`DexFile.entries()` 遍历类）。
同名路由后加载者覆盖前者。
